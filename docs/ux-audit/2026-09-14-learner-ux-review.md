### 3.1 试卷 / 模考待补测清单

本轮未深测考试链路。建议外审或下一轮按下列清单补测（仍排除 CSV 导入）：

1. **随机组卷**：题库详情 → 随机组卷 → 按题型数量生成 → 库存不足时的提示 → 生成后题目顺序固化（刷新不换题）。
2. **试卷详情**：题量、题型构成、开始答题 / 继续答题 / 查看成绩三种状态文案。
3. **答题中**：倒计时；交卷前不展示对错、解析、AI 点评；答题卡跳转；标记；左右滑；简答多行输入与保存。
4. **交卷**：未作答确认；超时自动交卷（若已实现）；交卷后不可改答。
5. **考试结果**：总分 / 正确率 / 耗时 / 题型分项；未作答是否单独列出（对照刷题 P1，避免同样把未答算错）。
6. **简答双轨**：正式分（参考答案模糊匹配）与 AI 建议分并存、文案标明「仅供参考」；失败可重试。
7. **考试复盘**：上一题 / 下一题 / 答题卡；客观题揭晓；简答展示作答、参考答案、建议分。
8. **真题模考**（`bank_kind === 'exam'`）：固定卷面顺序与分值；分节（若有）选择后再开考。
9. **历史**：考试会话出现在「未完成 / 已完成」，续考与看成绩跳转正确。
10. **与刷题对比**：考试不得提前揭晓；刷题即时反馈。两者底栏与顶栏「退出刷题」文案是否造成混淆。

## 4. 分节评价

### 4.1 用户体验

**整体**：暗色「夜径 · 提灯」气质统一，品牌名「习径」在顶栏、首页主标题处一致。学习者从首页进入题库、刷题、看结果、回错题本的主路径短，心智负担低。

**做得好的地方**

- 登录后首页同时给出「进入题库」与「继续学习」，续学展示题库名与进度（走查时为 61 / 63），符合「从上次停下的地方继续」。
- 刷题即时反馈明确：正确选项绿色、解析可读、揭晓后出现「AI 点评」。收藏与私人笔记放在揭晓后，不打断作答。
- 「暂不会」会收入错题本，错题本文案写明「答对不会自动移除」，预期清楚。
- 智能分析按考点聚合，并主动声明样本很小时「仅供参考」，与头条大数字形成对照（见 P1：对照反而暴露了口径错误）。
- 历史三分栏（未完成 / 已完成 / 已过期）符合会话生命周期。

**体验缺口**

- **结果头条误导（P1）**：中途结束时头条接近「3 / 63 正确、60 错误、5%」，而智能分析写明「本次仅 4 题、错 1 题」。用户会以为整卷只对了 5%，打击学习信心，也让 AI 总结看起来像在「打假」。
- **刷题简答无法作答（P1，潜在）**：走到下午案例简答时，界面没有作答框，只剩「暂不会」，「提交答案」保持禁用。学习者只能跳过，题目进入错题本，且无法练「写出来」。考试页代码侧有简答文本框，刷题页没有对等能力，两种模式体验断裂。
- **没有账号中心（P2 / 功能缺口）**：主题切换在顶栏月亮按钮；退出在底栏「退出」。看不到资料、显示名、角色、改密、登录邮箱。上传者与学习者共用底栏「退出」，和刷题顶栏「退出刷题」需靠场景区分。
- **底栏信息架构**：手机底栏为 题库 / 错题 / 历史 /（上传）/ 退出。收藏与笔记只在首页宫格，不在底栏；首页本身也不在底栏（点品牌回首页）。上传者多一枚「上传」后，五枚图标偏挤，且把「退出」做成常驻 Tab，误触成本高于「我的」。

### 4.2 布局与样式

走查视口为手机窄屏、暗色主题。组件以 Tailwind 工具类 + `src/style.css` 设计 token（`spark` / `surface` / `line` / `ok` / `bad`）为主，卡片圆角、底栏、选项按钮视觉一致。

| 页面 | 布局观察 |
|------|----------|
| 首页 | 主标题字号大、右侧金色路径装饰与文案「习惯成径」匹配；三列统计与 2×2 入口在窄屏可读；主按钮「进入题库」为金色实心，次操作为描边，层级清楚 |
| 刷题 | 顶栏进入专注模式（隐藏品牌字、显示「退出刷题」）；题型 chip + `1 / 63` + 进度条；选项热区足够；底栏答题卡 / 上一题 / 暂不会 / 提交答案一排排得下，主按钮仍是金色 |
| 结果 | 考点卡片纵向堆叠适合手机；总结与复习建议段落较长，需滚动，可接受；头条数字过大，错误口径时伤害更强 |
| 复盘 | 正确态绿框、「你的选择 / 正确答案」双芯片清晰；解析蓝底块与「AI 点评」按钮分层合理；底栏「下一题」为主操作 |

其它样式点：

- 主题切换有效，暗色为默认，符合产品设定。
- 刷题左右滑时，离场页与入场页短暂重叠，出现「鬼影」卡片（P2）。实现上切题使用绝对定位的 leave 层 + 半透明 enter 层，窄屏上两张题卡会叠在一起直到动画结束。

- 底栏已考虑 `safe-area-inset-bottom`；本轮未在 iOS 灵动岛真机上复核顶栏。

### P1-01 中途结束时，未作答被算进「错误」与正确率分母

- **页面**：刷题结果 `/result/:sessionId`（历史列表、首页正确率很可能同源）
- **现象**：约 63 题的会话里只做了约 4 题（含 1 错），头条接近 `3/63`、`60 错误`、`5%`。同页智能分析写「本次仅 4 题、错 1 题，样本很小」。
- **复现**
  1. 打开大题量题库，顺序刷题。
  2. 只答少数题（或穿插「暂不会」）。
  3. 用答题卡跳到末题并揭晓（作答或暂不会），点「查看结果」——或其它会把会话标为已完成的结束方式。
  4. 对比结果页顶部三元组与下方「总结」。
- **为何算 P1**：正确率是学习者最醒目的反馈；把未做题算错会否定实际表现，并与 AI 文案冲突。`REQUIREMENTS.md` PRACTICE-06 要求展示题数、正确数、错误数和正确率，但未要求把未揭晓题算错。
- **代码侧线索（供排期，非本 PR 修改）**：`computePracticeSummary` 使用 `wrong = total_count - correct_count`、`rate = correct / total_count`。`finish` 只回写 `correct_count` 与 `finished_at`，不区分已作答 / 暂不会 / 未作答。智能分析消费的是 `attempt_answers` 行，故口径正确。
- **建议方向**
  - 结果头条拆成：已作答、正确、错误（含或不含「暂不会」需产品拍板）、未作答；正确率分母用「已判定题」而非整卷题量。
  - 明确「暂不会」算错误、未作答、还是第三态；错题本已收录暂不会，结果页应与之一致。
  - 同步检查历史文案 `historyResultText`、首页/历史「正确率」，避免修了结果页、列表仍显示 5%。
  - 考试结果若同样调用该汇总函数，补测时一并核对（见 §3.1 第 5 条）。

### P1-02 刷题模式简答（案例问答题）没有作答输入，「提交答案」不可用

- **页面**：刷题 `/quiz/:bankId`，下午案例类简答
- **现象**：终局简答只看到题干与「暂不会」，没有文本框；主按钮「提交答案」禁用。学习者无法提交文字答案，只能跳过。
- **复现**
  1. 在含案例简答的题库中刷到 `short_answer`（或下午案例问答题）。
  2. 观察是否出现「你的作答」文本域。
  3. 确认未输入时提交按钮是否一直禁用。
- **为何算 P1（潜在）**：该题型在刷题路径上不可练习；只能「暂不会」→ 错题本 → 再打开仍可能同样无法写。考试页已有简答输入，能力不对称。若题库大量下午案例，主路径残缺。本轮只遇到一题，需用更多简答题确认是否 100% 复现。
- **代码侧线索**：刷题页选项区只渲染 `current.options` 按钮，`canSubmitAnswer` 要求 `selected.length > 0`。考试页对 `qtype === 'short_answer'` 使用 `textarea`。刷题题型圆点样式也未给简答单独分支。
- **建议方向**
  - 刷题对简答提供多行输入；提交后展示参考答案 / 要点（产品需决定：自评、模糊匹配，还是只展示不判分）。
  - 主需求曾写主观案例「不计入系统自动正确率」——若采纳，需与 P1-01 的分母规则一起设计。
  - 无选项时不要只留禁用的「提交答案」；应改主按钮为「提交文字」或提示「本题请输入作答，或点暂不会」。

### P2-01 左右滑切题时短暂叠影 / 鬼影卡片

- **页面**：刷题（考试页共用滑动组件，考试待补测）
- **现象**：滑动切换时两张题卡短暂重叠，随后稳定。未出现一次滑过两题。
- **复现**：在已揭晓或允许下一题时，左/右滑切题，盯着过渡的 0.5s。
- **建议方向**：过渡时裁剪轨道、降低离场透明度、避免 leave 层绝对定位与入场层同时占满视口；或缩短重叠区间。属动画打磨，不改动切题规则。

### P2-02 缺少个人资料 / 账号中心

- **页面**：全局。现有：顶栏主题、底栏退出、登录/注册/忘记密码。
- **现象**：无法查看登录邮箱、显示名、角色；改密只能走登录页「忘记密码」；没有「我的」。
- **建议方向**：增加轻量「我的」页（邮箱、显示名、角色只读、主题、改密入口、退出），底栏用「我的」替换常驻「退出」，降低误登出。非本轮阻断项。

### 观察项（未单列优先级）

- 底栏无「首页」「收藏」「笔记」；依赖顶栏品牌与首页宫格。可接受，但上传者五枚 Tab 偏满。
- 笔记列表未做编辑走查；错题「掌握状态」筛选未改状态，只确认下拉存在。
- 重置密码邮件链路未测。
- 桌面顶栏导航（题库/错题/收藏/笔记/历史）本轮以手机模拟为主，未专门测宽屏。
