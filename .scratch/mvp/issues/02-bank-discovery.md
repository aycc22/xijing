# 02: 题库搜索与详情页

**What to build:** 学习者可在题库广场按名称关键词搜索已发布题库，进入题库详情页查看简介、题目数、更新日期和发布者，并从此处选择学习方式（顺序刷题等入口）。空题库不能发布，也不能开始刷题或组卷。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 题库列表支持名称关键词搜索（BANK-03）
- [ ] 新增题库详情页：名称、简介、题目数、更新日期、发布者（BANK-02）
- [ ] 详情页提供「开始刷题」等学习入口
- [ ] 空题库禁止发布；已发布空库不可刷题（BANK-08）
- [ ] 列表与详情在手机端可用（360–430px）
