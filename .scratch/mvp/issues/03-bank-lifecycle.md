# 03: 题库生命周期与下架行为

**What to build:** 题库具备草稿、已发布、已下架、已归档状态流转。下架后不出现在题库广场且不能创建新会话；用户历史练习、答题结果、错题、收藏和笔记仍保留可查看。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 题库状态枚举覆盖草稿/已发布/已下架/已归档（§13.1）
- [ ] 下架题库不出现在学习者广场列表
- [ ] 下架后禁止创建新练习或答题会话
- [ ] 已有历史记录、错题、笔记仍可访问（AC-10, BR-03）
- [ ] 仅有用户记录的题库不可硬删除，只能归档（BR-12）
