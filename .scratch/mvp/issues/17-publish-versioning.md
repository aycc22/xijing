# 17: 发布版本与历史不变性

**What to build:** 题库发布保存版本号、发布时间和发布人；已发布题库改题后须再次发布才对学习者生效；用户已完成的历史成绩与当时题目内容不被重算。

**Blocked by:** 14: 试卷实例快照固化, 03: 题库生命周期与下架行为

**Status:** ready-for-agent

- [ ] 发布为原子操作；校验失败不得部分发布（PUBLISH-02）
- [ ] 发布记录版本号、时间、发布人（PUBLISH-04）
- [ ] 改题后学习者仍看旧版，再次发布后生效（PUBLISH-03）
- [ ] 发布前校验至少 1 道有效小题且结构合法（MANAGE-08）
- [ ] 上传者改标准答案并重新发布后，用户历史得分不变（AC-09, BR-09）
